# art/characters

Imagens dos ícones: `<id>.webp` (proporção 4:5, mínimo 640×800).

Para arquivos externos, registre fonte, autor, licença e atribuição em
`src/data/assets-manifest.json` (status `ready`). Para artes geradas, registre `origin`, autor,
prompt, atribuição e nota de direitos. Arquivos sem status `ready` fazem o CI falhar.
Guia completo: `docs/IMAGE_INTEGRATION.md`.
